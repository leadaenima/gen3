TASK B — Link battles (honest assessment)
-----------------------------------------
What Game3 cableClubNoLink / link specials do today:
  * Connect specials 28/29/30/36/341 → cableClubNoLink() sets
    VAR_RESULT = 5 (receptionist goodbye). No beginScriptWait.
  * CloseLink / partner-name / blender-sprite specials clear
    isLinkContest and return without waiting.
  * scriptGetMultiplayerId returns 4 (not-linked sentinel).
  * ShowLinkBattleRecords draws empty/total W-L-D from gameStats.
  * src/link/LinkBattle.lua is the Gen1/Gen2 Net.lua peer lockstep
    path — it is NOT wired into Game3 Cable Club / Colosseum scripts.

What full GBA link would require (not feasible here):
  * GBA SIO multiplayer (master/slave clock, JoyBus, serial IRQ timing).
  * Faithful link standby, trade/colosseum state machines, block
    transfer, and save-block record mixing.
  * Two real clients with matching ROM state — LÖVE has no GBA SIO.

Minimal safe improvements done:
  * cableClubNoLink clears isLinkContest and documents RESULT 5.
  * Added CABLE_CLUB_NO_LINK_MSG + cableClubNoLinkExplain() helper
    (not forced into scripts that already print goodbye text — avoids
    double dialogue).
  * Softlocks avoided: no waitstate on link connect stubs; multipplayer
    id stays 4; CloseLink does not soft-reset.

Verdict: full GBA Cable Club / Colosseum / Trade Center remains OUT OF
SCOPE. Local hotseat was not added (would be a new battle mode, not
ROM behavior). Gen1/2 LinkBattle over Net.lua is a separate feature.
