# Weather FX 8.2.12 — Native Gen2Recomped 3D Weather Host

Weather FX now recognizes Gen2Recomped's bundled `Gen2Recomped-DramaticShapes` voxel renderer as a native full-3D atmosphere host. Gold, Silver, and Crystal can therefore run Weather FX 3D clouds, precipitation, fog, lightning, celestial and connected-water presentation through the renderer already included with Gen2Recomped 0.7.40.

This is an in-memory compatibility bridge. Weather FX does not modify the host mod on disk and does not take ownership of Gen2's gameplay/weather mechanics. Existing 8.2.11 six-game generation and native battle-weather ownership rules are preserved.
