# Weather FX 8.1.21 — Player Control Expansion

Six new controls are added to the in-game Weather FX submenu system. Each is wired to a distinct runtime authority rather than acting as a cosmetic label.

- RAIN INTENSITY: OFF / 25 / 50 / 75 / 100 / 125 / 150 / 200%. Scales rain amount only.
- WIND INTENSITY: 25–200%. Scales the shared gust authority; never simulation/game/weather time.
- LIGHTNING FLASH: OFF / LOW / NORMAL / HIGH. Scales illumination, not strike timing or bolt ownership.
- STORM DARKNESS: OFF / LOW / NORMAL / HIGH. Scales 2D/battle dim and 3D weather-sky blend.
- TORNADO PLAYER PICKUP: OFF / RARE / NORMAL / FREQUENT = 0 / 3 / 10 / 25% per eligible new funnel.
- THUNDER VOLUME: 25–150%. Scales thunder voice volume after the tuned master mix while preserving distance and indoor attenuation.

8.1.20 WEATHER DURATION remains lifetime-only, and the Weather FX-owned shadow engine is unchanged.
